# vaultflux

Vault structured JSON flux payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/vaultflux/

## Install / run

```bash
git clone https://github.com/theworker02/vaultflux.git
cd vaultflux
node src/cli.js
node --test
```
